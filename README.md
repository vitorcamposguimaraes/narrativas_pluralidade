# Pluralidade — Rock in Rio 2026

Site estático preparado para GitHub Pages, construído com HTML5, CSS customizado, Bootstrap 5.3.3, Bootstrap Icons e JavaScript sem dependências de compilação.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `styles.css` e `script.js` para a raiz do repositório.
3. Em **Settings → Pages**, selecione **Deploy from a branch**.
4. Escolha a branch `main`, pasta `/ (root)` e clique em **Save**.

O site também funciona ao abrir `index.html` localmente. As fotografias são carregadas de URLs públicas da Pexels; para uso institucional, substitua-as pelas imagens oficiais autorizadas do Rock in Rio 2026.

## Arquivos

- `index.html`: conteúdo, estrutura semântica e componentes Bootstrap.
- `styles.css`: direção visual premium, responsividade, alto contraste e redução de movimento.
- `script.js`: filtros, capítulos interativos, progresso de leitura e painel de acessibilidade.
- `ANALISE-EDITORIAL.md`: fundamentos conceituais e critérios para a cobertura audiovisual.
